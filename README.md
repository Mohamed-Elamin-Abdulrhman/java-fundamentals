# Java Fundamentals
A structured collection of Java source files covering core object-oriented programming concepts, console I/O, data types, and arithmetic operations.
---
## 📁 Repository Contents

| File Name | Description |
| :--- | :--- |
| `basic_output.java` | Standard console output using `System.out.println()`. |
| `stringinputandoutput.java` | Text input reading using the `Scanner` class (`next()`) and string concatenation. |
| `numric_input_integers_float.java` | Handling primitive numeric inputs (`int` and `float`) via `nextInt()` and `nextFloat()`. |
| `oparetors_and_expressions.java` | Arithmetic operators (`+`, `-`, `*`, `/`, `%`), increment/decrement, and type casting. |
| `myclass.java` | Starter template demonstrating the basic Java class and `main` method structure. |

---
## 🛠️ Prerequisites & Compilation
Make sure you have the Java Development Kit (JDK 8 or newer) installed.
### Compile:
```bash
javac basic_output.java
